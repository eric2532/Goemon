# Asset origin

The gold mine geometry, material palette, animation data, and Blender-generation scripts were created for this Fire Siege asset request from the user-approved gold-mine concept sheet. The pack contains no imported third-party models, textures, stock sounds, or fonts. The preview contact sheet uses the system DejaVu Sans font for labels; that font file is not bundled.

The GLB uses procedural mesh geometry and built-in physically based material parameters. Its presentation PNGs and MP4 were rendered from the actual Blender model. The concept image is not used as a plane, texture substitute, or runtime asset.
