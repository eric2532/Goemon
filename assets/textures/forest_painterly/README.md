# Painterly ground v1

Generated on 2026-10-17 with the built-in image generation tool in **generate** mode. Original saved output copied unchanged into this repository as `painterly_ground_v1.png` (1254×1254). Used as a diffuse/albedo texture, world-space repeat 19 m, applied across the full map when the painterly preview is enabled. Roads use a warmer worn-earth tint. Also reused as a brush-variation mask on trees, wood, stone and buildings. No runtime dependency on the generator.
