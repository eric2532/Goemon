# Pinned source maps

Preserve these original LS2MAP bytes. Preparation writes derivatives under the
Asset Toolkit; it must not rewrite the source maps or their recorded hashes.

`wind-tower-references.json` pins fourteen connected Arcas/Wind Tower maps to
`linv2/Crossgate_Docker` commit `dd8690ed3df11e4eb5a038a54079a8f40d8e93b3`.
Each recovery checked the Git blob identity, byte count and SHA256. The client
archive supplies the independent recorded cell/flag plane. Map20003 is included
because the Arcas event explicitly transfers there after battle, not because
it has a neighboring ID. The one-way302→300 fixed port does not authorize an
unconditional reverse entrance.

Reproduce the staged source package with `python3 tools/prepare_sokia_wind_tower.py`.
Its preservation report and pending native/visual/event checks live in
`build/Other Files/Asset Toolkit/Sokia Venoa Coverage/Wind Tower/`.
The fourteen layouts are registered as gated review data; source presence does not
certify their original-release execution, gameplay access or scenery.
