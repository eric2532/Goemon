# Aoi art sources

`concept.png` is the user-approved illustration generated in this chat with
the built-in ImageGen tool. It uses Goemon's cobalt hair, red outfit and gold
trim as inspiration for an original compact Cross Gate-style adventurer.
The user subsequently requested the same sprite presentation as Kaz, a fourfold
longer pipe, and proportions that fit the original Cross Gate cast.

`face.png` was generated with built-in ImageGen as a flat UV texture. It is
packed into the editable Blender master; it is not a runtime portrait or sprite.
The generated texture is used unchanged. The following was its generation prompt:

> Generate a game asset, NOT a character portrait. A square flat painted facial-feature texture for the original blue-haired red-clothed young adventurer in the reference. The image fills the entire canvas with one perfectly uniform warm light peach skin color, no head silhouette and no hair. Centered facial features only: two large but compact blue anime eyes with dark navy upper eyelids, energetic friendly thick cobalt-dark brows, tiny understated nose indication, confident small open cheerful grin with a white tooth band, and two short red curved cheek marks. Straight front view, perfectly symmetric eyes, horizontal eye line. Eyes at x=.34 and .66, y=.46; brows y=.35; tiny nose y=.59; smile y=.68; cheek marks x=.25 and .75 y=.59. Central safe region x=.18 to .82 y=.30 to .74. Outside this region keep exact same plain warm light peach skin color with NO extra detail. Soft painted classic early-2000s Japanese RPG sprite aesthetic, clean shapes read at very small resolution. No skin lighting gradients, no dimensional skull, no contour, no ears, no hair, no neck, no clothing, no face outline, no shadows, no text. This canvas will be UV mapped onto a volumetric game character head. Preserve the reference's cheerful blue-eyed personality but keep features flat, simple and restrained.

The illustration and face used the existing Goemon/Cross Gate project references
for visual guidance. The final playable artwork is rendered offline from the
separate editable master at `assets/blender/characters/aoi/aoi.blend`.
The original Goemon, Ren and recovered Cross Gate assets remain intact.
