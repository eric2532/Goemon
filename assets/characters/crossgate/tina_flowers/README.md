# Tina crystal quest creatures

Prepared original appearances 110388–110391 (puk2:58–61) and crystal crab
101631 (original:2928). Recover with `python3 tools/recover_tina_explorer.py
--flowers`. The read-only source is the adjacent Magic Power archive.
Original palette pixels, eight source facings, frame timing, contact/audio
flags and PCM are prepared offline by the existing mantis/companion exporter.
Keep originals intact and regenerate this derivative instead of hand editing
atlases, frame tables or motion JSON. Native army combat and the shared hound
atlas renderer own presentation; `scripts/forest/crowd/tina_creatures.gd` binds
this data to the existing cave sprite slot. Source silhouettes are sprites,
not recovered 3D character meshes. Combat levels/formation come from the pinned
source records; HP, patrol posts and real-time crystal drops are adaptations.
