# Recovered retail Yae model

Source: Mystical Ninja Starring Goemon (USA), ROM SHA-256 `1603be37427a33548857fc3d2e8867ede71121c353fb631b79b44f1d94845d80`.

The model uses extracted file 299, facial definitions 300, static PIC set 301 and motion 302. Native file ID `0x12C` uses character index 3 and action table `0x80202228` in overlay 10. `body/body.json` preserves 42 display lists and 1,079 source vertex records, including two tagged `0x29…` body lists and the tagged `0x4900A350` bazooka sprite. There are 13 static/dynamic material images and 13 facial images. `motion.json` preserves all 232 source action rows and their native rates, covering 122 unique clips; excluded swimming, Mermaid and flute actions remain archival data only.

Every body part keeps its rigid source geometry, UVs, normals, color bytes, tile addressing and animation matrices. Original `801DAF54` / `801DB060` facial updates were executed for Yae to recover each action's face schedule. Godot mounts the source space at rotation PI and uses the shared Goemon/Sasuke source conversion `0.015158092072935184`; Yae is not independently normalized. Feet are placed on the ground from the native standing bounds. Native standing height is 2.79397708 game units.

Tier-three katana uses native action 68's handle `09007478` and blade `090026E8`. Native gold selection `8020448C[3*3+2] -> 80204474` contains `[090026E8,80204EB8,090044F0]`. Original PIC `801C`, loaded through file ID `0x80`, is bound to segment D. It was decoded directly from this ROM using original `80014698` / `80014D70` / `80014DD8`; its 4,096 decoded bytes hash to `2bceb9c40568cbec319709cd8e835dfb687118683f5291d53f4ffd06d04c9881`. The blade's original generated-linear coordinates use `gSPTexture 0800/1000`. Reach settings scale the rendered handle and blade about the source handle grip `(0,15,0)` and use that same transform for contact endpoints. At 1x every source matrix is unchanged.

Sword Shield uses its original 9C/9D/9E poses and the source blade; there is no invented shield mesh. Bazooka body is `09007BB8`. The original projectile renderer `80204D70` uses `4900A350`, callback `8006D920`, and source PIC at `090134D0`; the runtime factory renders its orange mirrored sprite as an unlit camera-facing billboard. Both normal and lock-on projectiles use this recovered art. The original texel-only combiner bypasses the unused vertex-normal bytes. Icons are direct renders of these assets. `portrait.png` is a full figure; `hud_portrait.png` is a separate tightly framed head render.

Validation and reproducible extraction scripts are in the canonical project's `build/Other Files/Yae ROM Recovery/Model/`. Exact source checks cover all 1,079 vertices, all 26 image pixel buffers and all 232 action mappings. Independent original-MIPS checks cover 30,663 channel values and 7,374 world matrices across frame 0/middle/end of every unique clip; maximum matrix error is 0.0000284121, with no mismatches above 0.0001. Godot model tests cover 13,293 rigid-part samples, native action timing, visible projectile art, locomotion, and real combat-node pose ownership. Reach tests verify fixed grip placement, visible/contact agreement at 3x, unchanged body proportions and exact return to 1x.

Rendering limit: native integer-frame matrices and source assets are retained; intermediate display frames interpolate rigid transforms in Godot, and body surfaces receive the current scene's lighting rather than emulating the complete N64 lighting pipeline. The recovered material shaders retain native three-point filtering, tile masks/mirrors and generated-linear gold coordinates.
