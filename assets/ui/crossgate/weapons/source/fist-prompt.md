# Wrapped fist icon

Initial wrist-only version, retained as source history. Superseded by
`fist-bandaged-master.png` and `fist-bandaged-prompt.md` after the user clarified
that bandages should surround the fist itself.

Generated 2026-11-15 with the built-in `image_gen` tool, transparent background.
The user allowed an original style consistent with the existing game art.
`fist-wrap-master.png` is the authoritative generated master. The runtime icon
is `../defaults/fist.png`, uniformly reduced to 48×48 with nearest-neighbor
sampling and the generated alpha retained. This source directory is excluded
from Godot imports/exports by `.gdignore`.

Final generation prompt:

Use case: stylized-concept. Asset type: a SINGLE production game UI inventory
icon for the Fist / Unarmed weapon category in a Cross Gate inspired early-2000s
Japanese RPG. Create an original clenched bare human fist with a small ivory
cloth wrap around the wrist, NOT a metal gauntlet, NOT an open glove. Four curled
knuckles and one tucked thumb, anatomically clear, sturdy compact silhouette.
Three-quarter isometric item view; knuckles toward upper-left, short wrist toward
lower-right. Style: deliberately small hand-painted PIXEL ART, limited warm
tan/peach/brown skin colors, ivory wrap, dark brown 1-pixel contour, short crisp
pixel-cluster highlights from upper-left and 3–4 stepped shadow tones. It must
sit naturally beside tiny 36–48 pixel swords, axes, wooden staves and bows with
subdued metallic highlights and brown outlines. Slightly expressive original
design, restrained and readable rather than an emoji or a modern flat vector
icon. Treat the complete art as a logical 48-by-48 pixel sprite; use perfectly
aligned square pixel blocks, no smooth anti-aliasing or micro-detail. If
delivering a larger image, enlarge this same tiny pixel design uniformly without
adding detail. One fist centered, completely visible, fills about 80 percent of
square canvas. Genuine alpha-transparent background. NO background panel, NO
checkerboard drawn into the artwork, NO scenery, NO frame, NO lettering, NO
labels, NO decorative sparkles, NO glow, NO motion lines, NO additional objects.
This is only an inventory/HUD icon, not a character or combat sprite.
