# Development recovery archive

These files are preserved for recovery and provenance. The active master is `../Final/Musashi_Final.blend`.

- `Musashi_Development_Backup.blend`: one byte-verified backup of the development file before final cleanup. Its reference artwork is packed, so it remains self-contained after the old development folders were archived.
- `Musashi_Visual_Development.zip`: nine previous development-stage folders, original reference copies, historical instructions and final-pass development scripts/intermediates. All 255 archived files were checked by ZIP CRC and individual SHA-256 before their active copies were removed.
- `development_archive_manifest.json`: original paths, sizes, hashes and archive verification record.

Do not load an archived iteration as the current approved character. Extract history into a separate recovery folder if it is explicitly needed.
