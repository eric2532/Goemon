# Asset provenance

The arrow tower, standalone arrow, gold mine, and construction effects were
procedurally authored as editable Blender geometry for this Fire Siege request,
following the user-approved generated concept direction. Included Python scripts
document the authoring process. The runtime assets do not incorporate downloaded
third-party meshes, texture packs, or stock model files. Materials are authored
in the asset sources and embedded in the GLBs; no concept illustration is used
as a substitute for modeled geometry.

Preview PNGs are rendered views of the actual 3D assets. The construction-effects
contact sheet uses an explicitly labeled placeholder pedestal. The tower and
mine contact sheets show their corresponding modeled assets.
The separate combined-demonstration hero render shows the actual tower and mine
with these construction effects attached; it remains a presentation scene.

This handoff does not choose a new repository license or grant an additional
open-source license. Redistribution and project licensing remain for the
repository owner to decide. Existing project terms are not changed. No external
third-party asset license is introduced by this package.

`SOURCE_PROVENANCE.json` records source-package filenames, original byte counts,
and SHA-256 values. Sources compressed for repository storage can be verified
against those original hashes after decompression.
