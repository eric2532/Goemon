# Fire Siege universal controls

Approved in conversation: use the original Fire Siege straight-lane map, original third-person camera and all existing hero combat skills. Retire player-facing cursor-combat versions. User selected camera-facing attacks, without cursor aiming or lock-on.

WASD moves relative to camera; Shift sprints; Space jumps. LMB primary, RMB secondary/hold block, C class evade, E extra utility, R signature, Q playable roster, F towers, G dogs, H companions. Explorer hook and Master Thief stance move to E; C gives those two a normal dodge. Other Rogue heroes keep their native evasions on C without a duplicate E evade. Goemon keeps C evade/E dash and all numbered/T skills. Edo remains selectable and retains his existing skills.

Manual attacks launch along horizontal camera heading; aim is captured for a swing. No cursor reticle or target lock. Native projectiles keep spread, timing and damage; Dragoon leaps forward at bounded native range, hooks select only valid visible forward anchors/foes. Preserve camera orbit, enemy waves, map, towers, cards, companions, collision and native cooldowns. Goemon's original automatic pipe triplet remains the Fire Siege profile.

Deliver a locally playable native macOS app and recorded visual verification. Keep the illustrated release and original repository checkout intact. No new GitHub release is required by this request.
