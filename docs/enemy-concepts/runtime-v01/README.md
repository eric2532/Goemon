# Forest enemy art captures

This folder contains captures of the approved detailed Forest enemy models. The live game also supports a low-fidelity renderer, so these images do not establish the current rendering default or balance values.

Editable sources: `assets/blender/enemies/forest_redesign_v01/` and `assets/blender/enemies/forest_redesign_v02/`. Runtime exports are under the matching `assets/models/enemies/` directories. Keep the models and source artwork intact.

Executable behavior and contact checks live under `tests/forest-shrine/`, including `enemy_roles_test.gd`, `enemy_visual_test.gd`, and `enemy_contact_test.gd`. Read the current implementation and saved balance for live stats. Old integration reports and build history are available in Git.
