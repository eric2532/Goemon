# Ninja dog concept references

These ten user-approved concept images were generated with OpenAI image generation, one image per dog. They are the exact original PNGs approved as visual references for Blender modeling.

Use these images as the source of truth for each dog's silhouette, colors, costume, and identifying details. Inspect the pixels before modeling; do not substitute text descriptions for the reference images.

`manifest.json` records each original file's byte count, SHA-256, and Git blob SHA for integrity checks.
